# Font licenses

The `.fnt` files in this directory are 1-bit rasters (generated by `tools/make_font.py`) of:

* **DejaVu Sans / Sans Bold / Sans Mono** (`s12 s16 b16 b24 b36 m12`) - Bitstream Vera /
  DejaVu licence: free to use, copy, modify and redistribute (derived fonts must not use the
  names "Bitstream Vera" or "DejaVu" without permission). https://dejavu-fonts.github.io/License.html
* **GNU Unifont** (`px16`) - dual licensed: GPL-2.0-or-later with the font embedding exception,
  or SIL Open Font License 1.1. https://unifoundry.com/unifont/

Rebuild with: `python3 tools/make_font.py --all` (needs the `fonts-dejavu-core` and
`fonts-unifont` packages on Debian/Ubuntu).
